# Bibi design system

UIKit iPhone app, iOS 16+. The generated recommendation was adapted to the anime product and the user-supplied native specification.

Rounded system type with UIFontMetrics. Bold titles, medium body. Original transparent bitmap icons; no application SF Symbols or emoji. Five root tabs (Shorts, Circles, Challenges, Chats, Me), 44pt minimum control targets and independent navigation stacks. Adaptive native constraints, full-window aurora, and editorial artwork separated from accessible live text. Illustrations are fictional, not real-user photos.

Illustrated discovery banners, 24–26pt rounded cards, 14pt grid gutters, a violet/pink floating dock, and cyan editorial eyebrow labels. Shorts keeps media foreground and gradient scrims. Native text, controls and user content never bake into screenshots.

Reduce Motion branches and VoiceOver labels are retained. Static palette contrast can be computed; device layout, dark behavior and accessibility have not been run. Current product appearance is deliberately light; this is not a claim of independent dark-mode support.
