# R2 Build Assets Implementation Plan

**Goal:** Resolve all asset sources through the owner's R2 URLs during builds, retain but never read the repository-root Assets directory, and exclude local assets from Git only after successful verification.

**Architecture:** A tracked URL/hash manifest describes every remote resource and the build subset. A standard-library downloader validates HTTPS origin, filenames, sizes and SHA-256, uses atomic writes and a verified generated cache, and never falls back to retained local files. XcodeGen and the Xcode pre-build phase prepare the downloaded native catalog and loose runtime resources. Runtime UIKit, media playback, fonts and agreement loading continue using the compiled bundle.

**User decisions:** Build-time downloading was explicitly selected in chat. Local Assets files must remain untouched and unused. The requested public origin is https://pub-fcd7cf821fc64e12885b1422fb08d0f5.r2.dev. The owner selected local HTML agreements in a separate repository-root Agreements directory. Generate them from the latest Google text, adapt delivery descriptions for offline reading, and bundle those tracked files. Never use retained Assets or obsolete R2 agreement copies.

## Constraints

- Preserve existing uncommitted work, app identity, iPhone-only destinations, stable data and all unrelated features.
